# YOLOv8篮球姿态检测项目编译环境准备指南

## 概述

本文档详细记录了YOLOv8篮球姿态检测项目在RK3588平台上的编译环境准备过程，包括遇到的问题、解决方案和配置要点。

## 项目架构特点

- **双NPU架构**: 充分利用RK3588的双核NPU资源
- **零拷贝优化**: NPU内存直接访问，消除CPU↔NPU数据传输开销
- **多线程设计**: 主线程姿态检测，副线程篮球检测
- **硬件加速**: 使用RGA硬件加速图像处理

## 编译环境准备

### 1. 系统依赖库安装

#### 必备系统库
```bash
# 更新包管理器
sudo apt update

# 安装基础编译工具
sudo apt install -y build-essential cmake pkg-config

# 安装Eigen3数学库（矩阵运算）
sudo apt install -y libeigen3-dev

# 安装OpenCV开发库
sudo apt install -y libopencv-dev

# 安装其他依赖
sudo apt install -y libv4l-dev v4l-utils
```

#### 依赖库说明
- **Eigen3**: 用于矩阵运算和线性代数计算，特别是卡尔曼滤波器
- **OpenCV**: 图像处理和计算机视觉操作
- **V4L2**: 摄像头驱动支持

### 2. RK3588专用库配置

项目使用的RK3588专用库已包含在`3rdparty`目录中：

```
3rdparty/
├── rknpu2/                     # RKNN NPU运行时库
│   ├── include/
│   │   └── rknn_api.h         # NPU API头文件
│   └── Linux/aarch64/
│       └── librknnrt.so       # NPU运行时库
├── librga/                     # RGA硬件加速库
│   ├── include/               # RGA头文件
│   └── Linux/aarch64/

    ├── include/
    └── Linux/aarch64/
        └── libturbojpeg.a
```

## 编译过程中遇到的问题与解决方案

### 问题1: CMake缓存路径错误

**错误现象:**
```
CMake Error: The source directory "/home/radxa/Qworkspace/yolov8_pose_basketball" does not exist.
```

**问题原因:** 
CMakeCache.txt中缓存了错误的绝对路径，之前在其他用户目录下配置过

**解决方案:**
```bash
cd build
rm -rf CMakeCache.txt CMakeFiles/*
cmake ..
```

**教训:** 
CMake会缓存绝对路径，迁移项目时需要清理缓存重新配置

### 问题2: RKNN头文件找不到

**错误现象:**
```
fatal error: rknn_api.h: No such file or directory
```

**问题原因:** 
CMakeLists.txt中缺少RKNN NPU库的头文件搜索路径

**解决方案:**
在CMakeLists.txt的`include_directories`中添加：
```cmake
include_directories(
    # ... 其他路径
    ${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/rknpu2/include
)
```

### 问题3: RKNN库文件链接失败

**问题原因:** 
缺少RKNN库文件的搜索路径

**解决方案:**
在CMakeLists.txt的`link_directories`中添加：
```cmake
link_directories(
    # ... 其他路径
    ${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/rknpu2/Linux/aarch64
)
```

### 问题4: Eigen库未安装

**错误现象:**
```
fatal error: Eigen/Core: No such file or directory
```

**问题原因:** 
系统未安装Eigen3开发库

**解决方案:**
```bash
sudo apt install libeigen3-dev
```

**验证安装:**
```bash
dpkg -l | grep eigen
find /usr/include -name "Eigen" -type d
```

## CMakeLists.txt配置要点

### 1. 头文件路径配置原则

使用相对路径而非硬编码绝对路径：
```cmake
# ✅ 正确做法：使用相对路径变量
${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/rknpu2/include

# ❌ 错误做法：硬编码绝对路径
/home/username/project/3rdparty/rknpu2/include
```

### 2. 库文件搜索路径

确保所有必要的库路径都已添加：
```cmake
link_directories(
    ${CMAKE_CURRENT_SOURCE_DIR}/libs
    ${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/rknpu2/Linux/aarch64
    ${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/librga/Linux/aarch64
)
```

### 3. 链接库配置

```cmake
target_link_libraries(yolov8_pose_basketball
    rknnrt                    # RKNN运行时库
    rga                       # RGA硬件加速库
    ${CMAKE_CURRENT_SOURCE_DIR}/3rdparty/jpeg_turbo/Linux/aarch64/libturbojpeg.a
    ${OpenCV_LIBS}            # OpenCV库
    pthread                   # 多线程支持
    dl                        # 动态链接库
)
```


## 总结

成功编译该项目的关键要点：

1. **系统依赖完整**: 确保Eigen3、OpenCV等库正确安装
2. **路径配置正确**: 使用相对路径，避免硬编码绝对路径
3. **RKNN SDK配置**: 正确配置NPU库的头文件和库文件路径
4. **CMake缓存清理**: 迁移项目时清理旧的CMake缓存
5. **编译环境**: 使用支持C++11的GCC编译器

通过以上配置，项目可以在RK3588平台上成功编译并充分利用双NPU硬件加速能力。
